# The Quiet Caravan: downloads

A cozy online exploration-and-crafting game: a shared camp, a kitchen, a market and day trips. Windows.

## Get the game

1. Download `QuietCaravanLauncher-<version>.zip` from the **launcher** release under [Releases](../../releases/tag/launcher).
2. Unzip it anywhere and run `QuietCaravanLauncher.exe`.
3. The launcher installs the game, tells you what is new, and keeps it up to date. After the first install it downloads only what changed.

Windows may warn about a new program; see the FAQ in the launcher (or `faq.md` here).

## What is in this repository

Only downloads. The game's source is private. Game versions are release attachments (a signed manifest plus the pieces that changed); the launcher reads them. The launcher's FAQ is `faq.md` on the `main` branch, and editing it updates the launcher without a new release.
