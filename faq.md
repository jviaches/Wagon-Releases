# The Quiet Caravan: questions and answers

## Getting started

### How do I install the game?
Download the launcher zip from the Releases page, unzip it anywhere and run `QuietCaravanLauncher.exe`. Press **Install and play**. The launcher tells you the download size first, installs the game, starts it and closes itself.

### Do I need an account or administrator rights?
No. The game and launcher install into your own user folder (`AppData\Local\QuietCaravan`) and nothing is installed system-wide.

### How big is the download?
The first install is the one big download, roughly 180–200 MB. After that the launcher fetches only the parts of the game that changed, usually a small fraction of that, and shows the size before you agree.

### Windows says it "protected your PC"
The launcher is a new program from a small studio, and Windows warns about those. Choose **More info**, then **Run anyway**, only if you downloaded it from this repository's Releases page.

## Updates

### How do updates work?
When you open the launcher it checks for a newer version. If there is one it offers **Update and play** or **Play installed version**. Nothing is replaced until you say yes, and the old version keeps working until the new one has finished installing and been checked.

### The download stopped halfway
Press the button again. What was already downloaded is kept, so it carries on from where it stopped. If the update fails, the installed version is untouched.

### The launcher can't reach the update server
You can still play the installed version. Check your connection and try again by reopening the launcher.

### Does the launcher update itself?
Yes. If a newer launcher exists it shows a banner with **Update launcher**. It replaces itself and restarts.

## Your saves

### Where are my saves?
In the `Saves` folder inside `AppData\Local\QuietCaravan`. Open it from **Help & links**, then **Open my saves folder**. Saves are kept outside the game versions, so an update or going back a version never removes them. Copy that folder somewhere safe if you want a backup.

### I played before the launcher existed. Can I keep my save?
Yes. Copy the `Saves` folder from your old game folder into `AppData\Local\QuietCaravan\Saves` before you start the new version.

## Problems

### The game is missing files or won't start
Open **Help & links** and choose **Check and repair the game**. It checks every file and downloads only what is missing or damaged. Your saves are not touched.

### Can I go back to the previous version?
Yes, once, from **Help & links**. A save made in a newer version may not open in an older one, so copy your `Saves` folder first.

### How do I uninstall?
Close the launcher and game, then delete the `AppData\Local\QuietCaravan` folder. That also deletes your saves, so copy `Saves` first if you want to keep them.

### Where do I report a problem?
Use **Report a problem** in **Help & links**, which opens this repository's Issues page. Say which version you have; it shows in the launcher and on the game's start screen.

## Playing together

### Can I play with friends?
Yes, two to six players. One player hosts and the others join their camp from the game's menu. Everyone needs the same version, so update before you play together.

### Is it ever required to play with others?
No. The game is better together but works fully alone.
